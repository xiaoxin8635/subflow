# SubFlow 手动测试指南（P2 全功能浏览器手测）

> 适用版本：P2.7（2026-10-11）。配合自动化 E2E 使用——E2E 已覆盖 API 层，本指南
> 重点验证**浏览器交互体验**：按钮是否可点、提示是否清晰、下载文件能否打开。
>
> 服务启动（Git Bash）：
> ```bash
> # 检查端口占用（若已启动跳过）
> netstat -ano | grep :3000 | grep LISTEN
> # 启动（必须 STORAGE_DRIVER=local，片段导出/烧录需要本地源文件）
> STORAGE_DRIVER=local npm start
> ```
> 打开 http://localhost:3000 。测试素材在 `test-media/`：
> `demo-video.mp4`（35 秒视频）、`demo-audio.mp3`（35 秒音频）。
> 验证码：任意手机号 + 万能码 `123456`（SMS_DEV_MODE）。

## 模块 A：注册登录 + 邀请裂变（P2.5）⭐ 重点

**准备**：两个没注册过的手机号（如 13811112222 / 13811113333），分别当「邀请人 A」和「被邀请人 B」。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| A1 | 用手机号 A 正常注册登录 | 进入工作台，右上角显示「30 分钟」注册赠送额度 |
| A2 | 工作台顶栏点「邀请好友」 | 跳转邀请页，显示一个 8 位邀请码（无 0/O/1/I），如 `PRNFMDPF` |
| A3 | 点「复制邀请链接」，粘贴到记事本查看 | 链接形如 `http://localhost:3000/login?ref=XXXX` |
| A4 | 检查邀请页统计区 | 已邀请好友 = 0，累计获得奖励 = 0，提示「还没有好友通过你的邀请注册」 |
| A5 | 退出登录（或无痕窗口），打开 A3 复制的链接 | 登录页出现**邀请码输入框且已自动填好** A 的邀请码 |
| A6 | 用手机号 B 完成注册 | 登录成功，B 的额度显示 **40 分钟**（30 注册赠送 + 10 邀请奖励） |
| A7 | 回到 A 的邀请页 | 已邀请好友 = 1；记录列表显示 B 的**脱敏手机号**（如 `138****2222`）+「+10 分钟」；累计获得奖励 = 10 分钟；A 的工作台额度变为 40 分钟 |
| A8 | B 退出后**再次登录**（这次不用管邀请码） | 正常登录，余额不变（老用户带码无效，不重复发奖） |
| A9 | （可选防刷）注册时手输一个不存在的码如 `XXXX2222` | 照常注册成功（30 分钟），**不报错、不发奖** |
| A10 | 检查 A 和 B 的工作台 → 兑换页附近的额度明细（流水） | A 多一条「邀请奖励 +10 分钟」，B 多一条「注册赠送 +30 分钟」和「被邀请奖励 +10 分钟」 |

**重点检查**：邀请码是否每次刷新页面都一样（懒生成只生成一次）；复制按钮点击后是否出现「已复制 ✓」反馈。

## 模块 B：上传 + 转写（P2.1 音频直传）⭐ 重点

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| B1 | 工作台点「+ 新建项目」，上传 `demo-video.mp4` | 分片上传进度正常，跳转项目页，状态走「转写中→润色中→完成」 |

**重点检查**：音频项目的项目详情页**不应出现「导出成片烧录」的旧入口**，取而代之是「片段裁剪导出」（见模块 E）。

## 模块 C：字幕编辑 + 时间轴批量调整（P2.3）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| C1 | 进入视频项目，点任意字幕行 | 播放器跳转到该句时间点 |
| C2 | 修改某句文字，不保存，刷新页面 | 提示有未保存修改或改动丢失（库内数据为准）；改完记得点「保存修改」 |
| C3 | 展开时间轴批量调整面板（编辑器内折叠区） | 有「整体偏移」和「整体伸缩」两组输入 |
| C4 | 整体偏移输入 `+2` 秒，确认 | 所有字幕行 start/end 各 +2；撤销按钮可一步还原 |
| C5 | 偏移 `-0.5` 秒（首行起点 0.5-0.5=0，合法） | 成功；再试 `-1` 秒 | 首行起点会变负 → **整批拒绝**并提示 |
| C6 | 整体伸缩输入 `1.5` 倍 | 所有时长拉长 1.5 倍（以首行起点为锚）；`0.5` 倍可还原 |
| C7 | 调整后点「保存修改」，刷新页面 | 调整结果已持久化 |

**重点检查**：偏移/伸缩后播放视频，字幕与语音是否仍大致对齐；撤销是否只回一步而不是全丢。

## 模块 D：自定义样式（P2.2）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| D1 | 编辑器右侧样式区，调大字号（如 6→9）、改字色为黄色 | 预览画面即时变化（所见即所得） |
| D2 | 点「把当前效果另存为我的模板」，命名「测试模板」 | 模板列表出现该模板，可选中/删除 |
| D3 | 不保存模板，直接微调字号到 12，然后点「导出视频」 | 成片按**当前预览效果**（12 号）烧录，不是模板里的 9 号——快照所见即所得 |
| D4 | 导出完成后删除「测试模板」，再下载刚导出的成片 | 下载不受影响（任务创建时样式已快照，模板删改不影响已建任务） |
| D5 | 下载字幕文件 ASS 按钮（带样式） | ASS 只认**模板库内**配置（微调未保存的部分不含，鼠标悬停有提示说明） |

**重点检查**：D3 的成片字幕样式确实跟着微调走了；字体描边清晰可读。

## 模块 E：片段导出（P2.6）⭐⭐ 本期核心

**视频项目**（用 B1 转写好的 35 秒项目）：

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| E1 | 导出卡勾选「只导出片段」 | 出现开始/结束两个输入框，各带「当前」按钮；预计消耗额度从 35 秒变化 |
| E2 | 播放视频到第 5 秒左右暂停，点开始的「当前」 | 开始框自动填入当前进度（如 `5.2`） |
| E3 | 播放到第 15 秒，点结束的「当前」 | 结束框自动填入；预计消耗 ≈ 10 秒额度 |
| E4 | 点「导出片段」 | 按钮变「导出中…」，几秒后变绿色「⬇ 下载片段」 |
| E5 | 下载片段，用播放器打开 | **时长约 10 秒**；第 5-7 秒处原字幕可见（跨边界句被截断属正常）；画面字幕样式与预览一致 |
| E6 | 下载的文件名检查 | 形如 `demo-video_片段_5.2-15s.mp4`（带原名+区间） |
| E7 | 勾选去掉「只导出片段」，走一次整片导出 | 正常出 35 秒完整成片，扣 35 秒额度（原链路无回归） |
| E8 | （负向）片段输入开始 `20`、结束 `5` | 导出按钮禁用，出现红字提示「结束需大于开始」 |

**音频项目**（用 B3 的 mp3 项目）：

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| E9 | 查看导出卡 | 显示「片段裁剪导出」表单（无样式选择——音频无画面不需要烧录样式） |
| E10 | 输入 5 → 15 秒，点「导出片段」 | 任务完成，下载得到 `.mp3` 文件，时长约 10 秒，能正常播放 |
| E11 | 检查额度扣减 | 两次片段各扣 10 秒（工作台余额对得上） |

**重点检查**：片段产物时长是否精准（±1 秒内）；额度扣减是否等于片段时长（不是整片时长）；工作台「导出中…」期间刷新页面任务状态是否还看得到。

| G2 | 未做翻译的新项目看同一位置 | 双语单选灰置，旁边提示「完成一次翻译后可烧录双语字幕」 |

## 已知边界（不是 Bug）

- 片段导出/整片导出**同一项目同时只能有一个任务**（第二个会提示 409 稍后再试）
- 字幕有未保存修改时导出按钮禁用（先保存）——防止导出的不是你看到的内容
- 片段跨过字幕句子边界时，该句字幕只保留片段内的可见部分（时间轴截断，属预期）
- 双语烧录按「当前最新的翻译版本」执行——导出排队期间重新翻译同一语言，
  未开始的任务会烧录新译文（已完成的任务不受影响）
- 音频项目没有双语烧录（无画面），但可以下载双语字幕文件给剪辑软件挂载
- E2E 自动化测试会消耗少量测试账号额度与 DashScope 费用，测试账号余额偏小是正常现象

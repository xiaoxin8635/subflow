# SubFlow 手动测试指南（P2 全功能浏览器手测）

> 适用版本：P2.16（2026-10-12，新建项目页「投料台」版式重构：大拖放区拖入
> 整块响应、文件行类型图标与动效、处理方式选择卡、识别设置折叠条；含 P2.15
> 空状态立体插画、P2.13 登录页左右分栏、P2.14 定价页套餐层次）。
> 配合自动化 E2E 使用——E2E 已覆盖 API 层，本指南
> 重点验证**浏览器交互体验**：按钮是否可点、提示是否清晰、下载文件能否打开。
>
> 服务启动（Git Bash）：
> ```bash
> # 检查端口占用（若已启动跳过）
> netstat -ano | grep :3000 | grep LISTEN
> # 启动（必须 STORAGE_DRIVER=local，片段导出/烧录需要本地源文件）
> STORAGE_DRIVER=local npm start
> ```
> 打开 http://localhost:3000 。测试素材在 `test-media/`：
> `demo-video.mp4`（35 秒视频）、`demo-audio.mp3`（35 秒音频）。
> 验证码：任意手机号 + 万能码 `123456`（SMS_DEV_MODE）。

## 模块 A：注册登录 + 邀请裂变（P2.5）⭐ 重点

**准备**：两个没注册过的手机号（如 13811112222 / 13811113333），分别当「邀请人 A」和「被邀请人 B」。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| A1 | 用手机号 A 正常注册登录 | 进入工作台，右上角显示「30 分钟」注册赠送额度 |
| A2 | 工作台顶栏点「邀请好友」 | 跳转邀请页，显示一个 8 位邀请码（无 0/O/1/I），如 `PRNFMDPF` |
| A3 | 点「复制邀请链接」，粘贴到记事本查看 | 链接形如 `http://localhost:3000/login?ref=XXXX` |
| A4 | 检查邀请页统计区 | 已邀请好友 = 0，累计获得奖励 = 0，邀请记录区显示信封插画 +「还没有好友通过你的邀请注册」 |
| A5 | 退出登录（或无痕窗口），打开 A3 复制的链接 | 登录页出现**邀请码输入框且已自动填好** A 的邀请码 |
| A6 | 用手机号 B 完成注册 | 登录成功，B 的额度显示 **40 分钟**（30 注册赠送 + 10 邀请奖励） |
| A7 | 回到 A 的邀请页 | 已邀请好友 = 1；记录列表显示 B 的**脱敏手机号**（如 `138****2222`）+「+10 分钟」；累计获得奖励 = 10 分钟；A 的工作台额度变为 40 分钟 |
| A8 | B 退出后**再次登录**（这次不用管邀请码） | 正常登录，余额不变（老用户带码无效，不重复发奖） |
| A9 | （可选防刷）注册时手输一个不存在的码如 `XXXX2222` | 照常注册成功（30 分钟），**不报错、不发奖** |
| A10 | 检查 A 和 B 的工作台 → 兑换页附近的额度明细（流水） | A 多一条「邀请奖励 +10 分钟」，B 多一条「注册赠送 +30 分钟」和「被邀请奖励 +10 分钟」 |

**重点检查**：邀请码是否每次刷新页面都一样（懒生成只生成一次）；复制按钮点击后是否出现「已复制 ✓」反馈。

## 模块 C：字幕编辑 + 时间轴批量调整（P2.3）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| C1 | 进入视频项目，点任意字幕行 | 播放器跳转到该句时间点 |
| C2 | 修改某句文字，不保存，刷新页面 | 提示有未保存修改或改动丢失（库内数据为准）；改完记得点「保存修改」 |
| C3 | 点右列工具条「时间轴」按钮展开批量调整面板 | 有「整体偏移」和「整体伸缩」两组输入；再点一次收起 |
| C4 | 整体偏移输入 `+2` 秒，确认 | 所有字幕行 start/end 各 +2；撤销按钮可一步还原 |
| C5 | 偏移 `-0.5` 秒（首行起点 0.5-0.5=0，合法） | 成功；再试 `-1` 秒 | 首行起点会变负 → **整批拒绝**并提示 |
| C6 | 整体伸缩输入 `1.5` 倍 | 所有时长拉长 1.5 倍（以首行起点为锚）；`0.5` 倍可还原 |
| C7 | 调整后点「保存修改」，刷新页面 | 调整结果已持久化 |
| C8 | 观察字幕列表每行 | 显示时间区间（如 `00:00.5–00:03.2`）+ 行下方细轨道条，标识该句在整片时间轴的位置；播放时当前句的轨道条变实色 |
| C9 | 点视频画面取得焦点后按 `空格` | 播放/暂停切换；`←`/`→` 快退/快进 2 秒；焦点在文本框内按空格不触发播放 |
| C10 | 修改文本后按 `Ctrl+S` | 触发保存，成功后按钮回「已保存」（再次修改才重新亮起） |
| C11 | 观察字幕列表顶部的波形条 | 显示真实音频波形（柱状起伏）+ 波形上叠加半透明**字幕段落块**（与行列表一一对应）；已播放区域淡紫染色 + 品牌色播放头随播放推进；点击/拖动波形空白处可定位（不自动播放）；键盘 Tab 聚焦后方向键可 ±2 秒 |
| C12 | 在波形条上**拖动某段落块的右缘**（鼠标移到块边缘变横向箭头） | 该句结束时间实时跟随（块上浮显 `mm:ss.d–mm:ss.d` 提示），松手后行列表时间区间同步更新，「保存修改」亮起；左缘同理调起点 |
| C13 | 拖动段落块**中间**左右平移 | 整句时间区间平移（时长不变）；块上按下不触发定位（与空白点击区分）；块内显示该句文字截断（更接近剪辑软件字幕轨） |
| C14 | 拖某句使其与相邻句**时间重叠** | 重叠的块立即变**琥珀警示色**（波形上+行列表提示「两句会同显」）；仅警示不拦截——配音重叠是合法场景；撤销或拖开即恢复品牌色 |
| C15 | 拖出边界（左缘拖到最左 / 右缘拖到最右） | 起点≥0、终点≤视频时长自动拦截；时长不足 0.1 秒的句子不会出现 |
| C16 | 拖错后经右列工具条「时间轴」打开面板点「撤销最近一次调整」 | 行区间一步还原（波形拖拽与整体偏移/伸缩共用撤销） |
| C17 | 新转写一个项目再进编辑器 | 新项目波形自动生成（旧项目/提取失败时无波形条，属预期退化） |
| C18 | 点右列工具条「查找替换」展开面板，查找词输入某句中出现的词 | 按钮显示「全部替换（N 段命中）」，N 与实际命中段数一致；再点一次按钮收起 |
| C19 | 输入替换词点「全部替换」 | 所有命中段文本更新；出现「已替换 X 处」提示与「撤销最近一次批量调整」按钮 |
| C20 | 点撤销 | 全部还原（与时间轴批量调整共用快照，保留一步）；重新替换后点「保存修改」刷新页面验证持久化 |
| C21 | 查找词填存在的词、替换词留空 | 替换 = 删除匹配文本（按钮可点）；空查找词时按钮禁用 |
| C22 | 点右列工具条「文稿TXT」 | 下载 `.txt`（文件名为项目标题），逐句一行，记事本/Excel 打开不乱码 |
| C23 | 点右列工具条「文稿MD」 | 下载 `.md`，每行 `**mm:ss.d** 句文本` 带时间戳格式 |

**重点检查**：偏移/伸缩后播放视频，字幕与语音是否仍大致对齐；撤销是否只回一步而不是全丢。

## 已知边界（不是 Bug）

- 片段导出/整片导出**同一项目同时只能有一个任务**（第二个会提示 409 稍后再试）
- 字幕有未保存修改时导出按钮禁用（先保存）——防止导出的不是你看到的内容
- 片段跨过字幕句子边界时，该句字幕只保留片段内的可见部分（时间轴截断，属预期）
- 双语烧录按「当前最新的翻译版本」执行——导出排队期间重新翻译同一语言，
  未开始的任务会烧录新译文（已完成的任务不受影响）
- 音频项目没有双语烧录（无画面），但可以下载双语字幕文件给剪辑软件挂载
- 加油包没有独立下单/支付系统——购买页只展示档位，收款仍走「扫码付款 + 客服发码」，
  档位只是让客服按对应秒数发码（发码页下拉已折算好，无需人工换算）
- 个别视频封面抽帧失败（如损坏文件/特殊编码）时卡片显示渐变占位图，转写不受影响——
  占位图不是 Bug；音频项目永远没有封面（设计如此）
- OCR 项目的视频预览/烧录导出时，新字幕叠在原字幕上属预期（原字幕烧死在画面里去不掉）；
  要「干净」的字幕请用语音转写项目
- E2E 自动化测试会消耗少量测试账号额度与 DashScope 费用，测试账号余额偏小是正常现象
